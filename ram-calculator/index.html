How this works

For catalog packs, the starting size is the one set for that pack in the live catalog. For other packs, it's the size most pack listings and public server guides recommend for a small group, checked October 2026. For bigger groups we add about 1 GB for every 3 extra players, a common rule of thumb for modded servers, so those sizes are estimates.
